# HEI Wander Type

A wandering-line type generator. Every glyph is retraced by a line that gets lost on the way. Works with Chinese and Latin text.

Open `index.html` in a browser, or enable GitHub Pages for this repository.

- Canvas: fit to text, ratio (1:1 to 21:9, A4) or custom size, with output long side in px
- Text case, horizontal or vertical layout
- Seed number with previous / next / random, lock shape
- Web fonts or any font installed on your computer
- Glyph width, height, letter spacing
- Wander amplitude, inertia and speed (the line keeps moving)
- Stroke weight, preview zoom
- Export SVG, PNG, or copy SVG; click a glyph to reroll it
